# ESP Programmer

Графическая утилита для ESP32, ESP8266 и ESP8285.

## Возможности

- определение подключённого ESP;
- чтение MAC-адреса;
- определение размера Flash;
- сохранение полного дампа Flash;
- просмотр BIN в HEX;
- поиск текста и HEX-последовательностей;
- переход к адресу;
- просмотр байта в HEX, DEC, BIN и ASCII;
- чтение ESP32 partition table;
- таблица адресов и размеров разделов;
- схематическая карта Flash;
- переход из таблицы разделов в HEX Viewer.

## Запуск

```bash
cd tools/esp_programmer
./run.sh

ESP8266 и ESP8285 не используют стандартную ESP32 partition table.
